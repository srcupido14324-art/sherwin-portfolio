# Sherwin Cupido Portfolio

This folder is the complete static website. It includes the page, styling, portrait, thumbnails, and short video previews. It does not require ChatGPT or OpenAI Sites to run.

## Publish with GitHub Pages

1. Sign in to a GitHub account and create a **public** repository named `sherwin-portfolio`.
2. Upload all files in this folder to the repository root, including `.nojekyll` and `assets/`.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. GitHub will show the live address in **Settings → Pages** once publication finishes. The expected address format is `https://YOUR-USERNAME.github.io/sherwin-portfolio/`.

The website uses relative asset paths, so it can also be uploaded to another static host. The contact email and external YouTube links are in `index.html`. The page layout is in `style.css`, and the project filters and video player are in `app.js`.

The portfolio source files and video previews are public when placed in a public repository. Keep a copy of this folder or its ZIP backup on storage you control.
